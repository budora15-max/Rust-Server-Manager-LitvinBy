# Участие в разработке

Спасибо, что хотите помочь проекту!

## Как внести вклад

1. **Форк** репозитория и создайте ветку: `feat/feature-name` или `fix/bug-name`.
2. Вносите изменения в соответствии с принятыми стилями:
   - TypeScript, строгие типы (оба `tsconfig`), без `any` там, где можно обойтись.
   - Форматирование — 2 пробела, LF, `prettier`-совместимо.
   - Новые IPC-методы: тип в `electron/types.ts` + `src/types`, мост в `preload.ts`, декларация в `src/vite-env.d.ts`.
   - Локализация: ключи добавляются в **оба** файла `src/locales/{ru,en}/translation.json`.
3. Для чистых модулей main-процесса (без `electron`-импортов) — **тест** в `tests/` на `node:test`.
4. Проверьте перед PR:
   ```bash
   npm run typecheck
   npm test
   npm run build:web   # быстрая проверка сборки фронтенда
   ```
5. Откройте Pull Request с описанием изменений и (если применимо) скриншотами.

## Структура коммитов

Необязательно, но приветствуется conventional-стиль:
`feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`.

## Что не принимается

- Скрытые зависимости без необходимости (предпочитаем чистый Node/`node:test`).
- Несанкционированное использование материалов Facepunch/umod в коде.
- Ломающие изменения без обсуждения в issue.
