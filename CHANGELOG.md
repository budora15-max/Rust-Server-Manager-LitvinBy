# Changelog

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено

## [1.0.1] — 2026-08-18

### Добавлено
- Вкладка General: раздел «Game mode & identity» — выбор игрового режима сервера (`gamemode`: vanilla, softcore, hardcore, primitive) с записью в `server.cfg` и аргументом `+gamemode` при запуске; поле `server.identity` с показом пути сохранений `server/<identity>`.
- Выбор игрового режима в окне создания сервера и отображение режима на карточке сервера.
- Полный набор настроек сервера во вкладке General: имя сервера (`server.name`, лимит 64/32 с валидацией), карта (`server.level`: Procedural Map / CraggyIsland), кастомная карта (`server.levelurl`), описание (`server.description`, `\n` — перенос строки), ссылка (`server.url`), картинка (`server.headerimage`) и логотип (`server.logoimage`), теги (`server.tags`, максимум 3: pve, roleplay, creative, minigame, training, battlefield, broyale, builds) + теги периодичности вайпов и региона, интервал сохранений (`server.saveinterval`, сек.), дополнительные аргументы запуска, автообновление сервера и Oxide при (пере)запуске.
- Ещё поля настроек: `server.tickrate` (30/60/100), `server.queryport` (по умолчанию порт игры + 1, с автосдвигом при смене порта), `server.password` (пароль на вход), античит `server.secure` (EAC/VAC) и Steam-ветка для SteamCMD (`-beta`, например publicbeta).
- Синхронизация счётчика плагинов: число плагинов на карточках и в «Свойствах сервера» обновляется автоматически (при старте менеджера, открытии страницы сервера и после операций с плагинами).
- Валидация RCON-пароля: минимум 8 символов и только `A-Z a-z 0-9 _ . -`.
- Размер мира теперь ограничен 1000–6000 (как в референсе).

## [1.0.0] — 2026-08-17

### Добавлено
- Управление серверами: запуск/остановка/перезапуск реального процесса, watchdog (краш + зависание), обнаружение внешних серверов.
- RCON (WebRcon): консоль с живым логом и командами, быстрые команды, список игроков, бан-лист, kick/ban/unban, временные баны с авторазбаном.
- Плагины: Oxide, вкл/выкл, обновление с uMod, редактор JSON-конфигов, каталог и живой поиск по uMod.
- Моды: установка/обновление/удаление фреймворка Oxide (uMod).
- Вайпы (ручные и по расписанию), бэкапы мира (вручную и автобэкапы с ротацией), ежедневные перезапуски с предупреждениями в чат.
- Метрики и история посещаемости с графиками, браузер логов сервера.
- Центр уведомлений + системные уведомления Windows, Discord и Telegram вебхуки.
- Трей, автозапуск с Windows, автозапуск серверов, вкладка «Порты» + Windows Firewall, экспорт/импорт конфига.
- Локализация RU/EN, сгенерированная иконка приложения.
- Модульные тесты (`node:test`) — `npm test`.

### Исправлено
- Устаревшие строки прошлых сессий больше не подгружаются в консоль, когда сервер не запущен; лог показывается с начала текущей сессии.
- Консоль не подменяет реальный ответ RCON фейковым «успехом» при неподключённом RCON.
- Дублирование бэкапов в одну миллисекунду (уникальные имена).
- Каталог плагинов: живой поиск по uMod, в т.ч. малопопулярные плагины по точному slug (например, Admin Chatroom).
- Счётчик плагинов во вкладке «Моды» учитывает identity-папку Oxide (`server/<identity>/oxide`).
