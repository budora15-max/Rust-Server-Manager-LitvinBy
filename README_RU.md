# Rust Server Manager LitvinBY

Десктопная утилита под Windows и Linux для управления выделенными серверами Rust (процессы, RCON, моды, вайпы, бэкапы). *Неофициальный проект, не связанный с Facepunch Studios.*

## Основные возможности

* **Управление сервером:** Контроль процессов `RustDedicatedServer.exe`, встроенный watchdog для перезапуска при зависаниях, умные конфигурации и обновление через SteamCMD.
* **RCON и игроки:** Поддержка WebRcon, живые логи и чат, администрирование игроков (баны, кики).
* **Плагины и Oxide (uMod):** Установка и удаление Oxide, сканирование и редактирование модов, каталог плагинов.
* **Автоматизация и бэкапы:** Планировщик задач для вайпов и рестартов, создание резервных копий мира.
* **Мониторинг:** Метрики в реальном времени (FPS, CPU, RAM), история аналитики и пуш-уведомления.
* **Инфраструктура:** Поддержка Linux, работа в фоне (системный трей), проверка портов и экспорт профилей.

## Технологии и быстрый старт

* **Стек:** React 18, TypeScript, Tailwind CSS, Electron 29, Vite 5, Node.js.
* **Требования:** Node.js 20+, Windows или Linux.
* **Запуск:** 
  1. `npm install` (установка зависимостей)
  2. `npm run dev` (запуск Vite)
  3. `npm run electron:dev` (запуск Electron)
