Десктопная утилита для Windows и Linux, разработанная для управления выделенными серверами Rust. Мониторинг процессов, RCON, моды, вайпы и бэкапы — все в одном удобном окне.

**Важно:** Это неофициальный проект. Он никак не связан с Facepunch Studios. Названия «Rust» и «Oxide» принадлежат их законным владельцам.

---

## Возможности

### 🖥️ Управление сервером
- **Контроль процесса:** запуск, остановка и перезапуск `RustDedicatedServer.exe`. При перезапуске менеджера он автоматически переподключается к активному процессу сервера.
- **Встроенный Watchdog:** автоматический перезапуск сервера при сбоях (до 3 раз за 30 минут) или при зависании консоли.
- **Умные конфиги:** генерация безопасных RCON-паролей и автоматическое исправление сломанных кавычек в `server.cfg` для значений с пробелами.
- **Гибкие настройки:** управление режимами игры (vanilla, softcore, hardcore, primitive), путями сохранения, картами (Procedural, CraggyIsland, custom URL), тегами, тикрейтом, портами и расписанием вайпов.
- **Обновление в один клик:** обновление сервера и Oxide через SteamCMD с визуальным отображением прогресса загрузки в реальном времени.

### 💬 RCON и управление игроками
- **Поддержка WebRcon:** полное соответствие стандарту Facepunch с системой автоматического восстановления соединения.
- **Живые ленты:** доступ к логу консоли в реальном времени, стриму чата и быстрым командам.
- **Администрирование игроков:** просмотр игроков в сети, управление черными списками, кики, баны и временные баны с автоматическим снятием по расписанию.

### 🧩 Плагины и Oxide (uMod)
- **Простая установка:** установка, обновление и полное удаление Oxide (uMod) прямо в корневую директорию сервера.
- **Сканер плагинов:** сканирование активных плагинов, их временное отключение через расширение `.disabled` и редактирование JSON-конфигураций во встроенном редакторе.
- **Интеграция с каталогом uMod:** просмотр директории uMod прямо из приложения. Доступ к описаниям, счетчикам скачиваний и быстрая установка `.cs` плагинов.

### 🔄 Вайпы, бэкапы и автоматизация
- **Ручные вайпы:** очистка файлов `.map` и `.db`, генерация новых сидов и переключение циклов автоматической остановки/запуска сервера.
- **Продвинутый планировщик задач:** автоматизация вайпов, ежедневных перезапусков с настраиваемыми предупреждениями в игровой чат и ротация резервных копий. Планировщик работает в основном процессе, поэтому он не прервется, даже если закрыть окно интерфейса.
- **Бэкапы мира:** простое создание, восстановление и удаление резервных копий мира.

### 📊 Мониторинг и уведомления
- **Метрики в реальном времени:** отслеживание активных игроков, FPS сервера, нагрузки на CPU и использования RAM.
- **Историческая аналитика:** графики количества игроков и производительности с фильтрацией по дням, неделям или месяцам.
- **Просмотр логов:** изучение подробных логов сервера со встроенным поиском и фильтрами по категориям.
- **Мгновенные оповещения:** поддержка нативных пуш-уведомлений Windows + вебхуки в Discord и Telegram.

### 🌐 Инфраструктура и сеть
- **Фоновый режим:** сворачивание в системный трей, автозапуск при старте Windows и автоматический запуск сервера.
- **Вкладка управления портами:** определение процессов, конфликтующих с вашими портами, создание правил Брандмауэра Windows (требуются права администратора/UAC) и проверка доступности внешних портов по TCP.
- **Кроссплатформенная поддержка Linux:** нативная обработка процессов `RustDedicated`, бета-ветки SteamCMD (`-beta`), отслеживание процессов через `ps`, анализ портов с помощью `ss`/`netstat`, интеграция автозапуска `.desktop` и автоматическая сборка CI для AppImage/deb.
- **Портативность данных:** экспорт и импорт профилей сервера и конфигураций с полной встроенной локализацией на RU/EN.

## Стек технологий

- **Frontend UI:** React 18, TypeScript, Tailwind CSS, lucide-react
- **Backend Core:** Electron 29, Vite 5, i18next
- **Runtime и утилиты:** Node.js, `ws` (WebRcon), `pidusage`, `adm-zip`
- **Тестирование:** встроенный `node:test` (ноль внешних зависимостей)
- **Сборка:** electron-builder (NSIS + портативные пакеты)

## Быстрый старт

### Требования
- Node.js 20+
- ОС Windows или Linux (Примечание: для управления Брандмауэром Windows требуются права администратора).

### Настройка для разработки

1. **Установите зависимости:**
   ```bash
   npm install

    Запустите dev-сервер Vite:
    bash

    npm run dev

    Скомпилируйте основной процесс и откройте окно Electron:
    bash

    npm run electron:dev

### Качество и сборка
* **Проверка типов рендерера:** `npm run typecheck`
* **Запуск модульных тестов:** `npm test` (компилирует основной процесс + запускает тесты)
* **Сборка для продакшена:** `npm run build` (собранные установщики будут созданы в папке `/release`)

## Структура проекта

* `electron/` — Основной процесс: IPC-контракты, сторожевой таймер, RCON-клиент, планировщик и сервисы оповещений.
* `src/` — Интерфейс React: страницы, вкладки компонентов и глобальные провайдеры контекста.
* `tests/` — Тестовые наборы на основе `node:test`.
* `scripts/` — Вспомогательные утилиты (например, генераторы ассетов и иконок).
* `build/` — Сборочные ассеты, графика брендинга и иконки приложения.

*Для более глубокого понимания архитектуры приложения и IPC-контрактов обратитесь к `ARCHITECTURE.md`.*
