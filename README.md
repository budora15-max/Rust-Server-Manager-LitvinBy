# Rust Server Manager LitvinBY

Десктопная утилита под Windows для управления выделенными серверами Rust. Позволяет контролировать процессы, работать с RCON-консолью и настраивать моды в одном окне.

> **Важно:** Это неофициальный проект. Он никак не связан с Facepunch Studios. Названия Rust и Oxide принадлежат их законным владельцам.

## Что умеет программа

### Управление сервером
* Запуск, остановка и рестарт `RustDedicatedServer.exe`. Если сам менеджер перезагрузился, он подхватит уже активный процесс сервера.
* Встроенный Watchdog: автоматом перезапускает сервер при крашах (до 3 раз за полчаса) или если консоль намертво зависла.
* Базовая работа с конфигами: сам генерирует безопасный RCON-пароль и чистит кавычки в `server.cfg` для значений с пробелами.
* Быстрое переключение игровых режимов (vanilla, softcore, hardcore, primitive) и путей для сохранений (`server.identity`).
* Полная настройка параметров: лимиты имени сервера, выбор карт (Procedural, CraggyIsland или по кастомной ссылке), теги, расписание вайпов, тикрейт и порты.
* Обновление сервера и Oxide в один клик через SteamCMD (с отображением прогресса загрузки).

### RCON и игроки
* Работает через стандартный протокол Facepunch WebRcon с возможностью фолбэка.
* Живой лог консоли, поток чата и панель для быстрых команд (избранное).
* Списки игроков онлайн, бан-листы, быстрый кик/бан и система временных банов с авторазбаном по таймеру.

### Плагины и Oxide
* Установка, обновление и удаление Oxide (uMod) прямо в корневую папку сервера.
* Сканирование установленных плагинов, отключение через добавление `.disabled` и встроенный редактор JSON-конфигов.
* Прямой поиск по каталогу uMod внутри приложения: показывает описание, количество скачиваний и качает `.cs` файлы на лету.

### Вайпы, бэкапы и автоматизация
* Ручной вайп (удаление файлов `.map`/`.db` и генерация нового сида) с автоматической остановкой и перезапуском сервера.
* Планировщик задач: отвечает за вайпы, ежедневные рестарты с предупреждениями в игровой чат и автобэкапы с ротацией. Работает в основном процессе (main), поэтому скрипты не прерываются, даже если закрыть окно программы.
* Бэкапы мира: создание, восстановление и удаление резервных копий карт с уникальными именами по таймстампу.

### Мониторинг и уведомления
* Сбор метрик в реальном времени через RCON и опрос процесса (онлайн, FPS сервера, нагрузка на CPU и оперативную память).
* Графики истории посещаемости сервера за последние 24 часа, неделю или 30 дней.
* Встроенный просмотрщик логов сервера с текстовым поиском и фильтрацией по уровню важности.
* Центр уведомлений: интеграция с системными пушами Windows, а также отправка алертов через вебхуки в Discord и Telegram.

### Инфраструктура
* Сворачивание в трей, автозапуск приложения вместе с Windows и автоматический старт серверов при запуске менеджера.
* Вкладка «Порты»: проверка занятости локальных портов (показывает, какой процесс мешает запуску), управление правилами Windows Firewall (требуются права админа/UAC) и проверка доступности портов по TCP снаружи.
* Поддержка Linux: работа с нативным `RustDedicated`, поддержка бета-веток SteamCMD (`-beta`), отслеживание процессов через `ps`, проверка портов через `ss`/`netstat`, автозапуск через XDG `.desktop` и автоматическая сборка AppImage/deb пакетов в CI.
* Профили: быстрый экспорт/импорт конфигурации серверов и нативная локализация интерфейса (RU/EN).

## Технологии

* **UI:** React 18, TypeScript, Tailwind CSS, lucide-react
* **Backend приложения:** Electron 29, Vite 5, i18next
* **Ядро (основной процесс):** Node.js, библиотеки `ws` (для WebRcon), `pidusage`, `adm-zip`
* **Тестирование:** встроенный модуль `node:test` (абсолютно без внешних зависимостей)
* **Сборка:** electron-builder (сборка инсталляторов NSIS и portable-версий)

## Быстрый старт

Для работы нужны Node.js версии 20+ и операционная система Windows или Linux (управление брандмауэром Windows работает только на Windows под админом).

```bash
# Установка зависимостей
npm install

# Режим разработки (запуск Vite dev-server + Electron)
npm run dev
npm run electron:dev   # Компилирует main-процесс и открывает окно Electron

# Проверки и тесты
npm run typecheck      # Проверка типов в рендерере (React)
npm test               # Автоматическая компиляция main + прогон модульных тестов

# Продакшн-сборка под Windows (готовые установщики появятся в /release)
npm run build
```

## Структура проекта

- `electron/` — основной процесс: IPC, вотчдоги процессов, RCON, планировщик, вебхуки
- `src/` — процесс рендерера (интерфейс на React: страницы, вкладки, контексты)
- `tests/` — модульные тесты на базе `node:test`
- `scripts/` — вспомогательные скрипты для разработки (генерация иконок)
- `build/` — ресурсы для сборщика (иконки, графика установщика)

Подробный разбор архитектуры и контрактов IPC лежит в файле [ARCHITECTURE.md](ARCHITECTURE.md).

## Доступные команды

* `npm run dev` — запуск dev-сервера Vite для фронтенда.
* `npm run electron:dev` — сборка главного процесса и запуск Electron для разработки.
* `npm run typecheck` — проверка типов TypeScript в папке рендерера.
* `npm test` — автоматическая компиляция и запуск модульных тестов.
* `npm run build` — полная сборка приложения и создание установщиков Windows.
* `npm run build:web` — сборка чистого фронтенда (можно использовать для браузерного демо).
