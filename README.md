# Rust Server Manager

Десktop-приложение для управления выделенными серверами **Rust** (Windows): запуск/остановка, RCON-консоль, игроки, плагины, вайпы, бэкапы, расписания, мониторинг и уведомления — всё в одном окне.

> ⚠️ Неофициальный проект, не связан с Facepunch Studios. Названия Rust и Oxide принадлежат их владельцам.

## Возможности

### Сервер
- Запуск/остановка/перезапуск реального процесса `RustDedicatedServer.exe`, обнаружение внешних серверов после рестарта менеджера.
- Watchdog: авторестарт при краше (до 3 раз / 30 мин) и при «зависании» (нет вывода N минут).
- Генерация безопасного RCON-пароля, санитизация `server.cfg` (кавычки для значений с пробелами), редактор конфига.
- Настройка игрового режима (`gamemode`: vanilla/softcore/hardcore/primitive) и идентичности сервера (`server.identity` + путь сохранений `server/<identity>`).
- Полный набор настроек сервера: имя (лимит 64/32), карта (`server.level`: Procedural Map / CraggyIsland) и кастомная (`server.levelurl`), теги (`server.tags`, до 3) + частота вайпов и регион, описание с `\n`, ссылка/картинка/логотип, интервал сохранений (`server.saveinterval`), тикрейт (`server.tickrate`), queryport, пароль на вход (`server.password`), EAC (`server.secure`), доп. аргументы запуска, Steam-ветка (`-beta`) и автообновление сервера и Oxide при (пере)запуске.
- Обновление серверной части через **SteamCMD** с прогрессом.

### RCON
- **WebRcon** с официальным методом Facepunch (пароль в URL) и фолбэком на `rcon.login`.
- Консоль: живой лог процесса + отправка команд, поток чата/ответов, **быстрые команды** (избранное).
- Игроки: список онлайн (JSON `playerlist`), бан-лист, kick/ban/unban, **временные баны с авторазбаном**.

### Плагины и моды
- **Моды**: установка/обновление/удаление фреймворка **Oxide (uMod)** прямо в папку сервера.
- Плагины: сканирование Oxide, включение/выключение (`.disabled`), обновление с uMod, **редактор JSON-конфигов**.
- **Каталог**: живой каталог и поиск по uMod (описание, версия, загрузки, установка `.cs`).

### Вайпы, бэкапы, расписания
- Ручной вайп (`.map`/`.db`, новый сид) с автоостановкой/перезапуском сервера.
- **Планировщик**: вайпы, ежедневные перезапуски с предупреждениями в чат, автобэкапы с ротацией — всё выполняется в main-процессе и переживает закрытие окна.
- Бэкапы мира (создание/восстановление/удаление, уникальные имена).

### Мониторинг и уведомления
- Метрики процесса + RCON (игроки, FPS, CPU, RAM), **история посещаемости** с графиками за 24ч/7д/30д.
- Браузер логов сервера с поиском и фильтрами.
- **Центр уведомлений** + системные уведомления Windows, **Discord** и **Telegram** вебхуки.

### Инфраструктура
- Трей, автозапуск с Windows, автозапуск серверов вместе с менеджером.
- Вкладка **«Порты»**: локальный статус портов (кто занял), управление **Windows Firewall** (UAC), TCP-проверка доступности.
- Экспорт/импорт конфигурации сервера, локализация **RU/EN**.

## Технологии

| Слой | Стек |
|---|---|
| UI | React 18, TypeScript, Tailwind CSS, lucide-react |
| Процесс | Electron 29, Vite 5, i18next |
| Backend | Node (main-process), `ws`, `pidusage`, `adm-zip` |
| Тесты | `node:test` (без внешних зависимостей) |
| Сборка | electron-builder (NSIS + portable) |

## Быстрый старт

```bash
# установка зависимостей
npm install

# разработка (Vite dev-server + Electron)
npm run dev
npm run electron:dev   # собрать main и запустить Electron

# проверки
npm run typecheck      # tsc рендерера
npm test               # tsc electron + node --test (модульные тесты)

# продакшн-сборка Windows (NSIS + portable) в release/
npm run build
```

> Требуется Node.js 18+ и Windows (для полной функциональности: процессы Rust, Firewall, SteamCMD).

## Структура проекта

```
electron/        main-процесс (IPC, процессы, RCON, плагины, планировщик, уведомления)
src/             рендерер (React: страницы, вкладки, контексты)
tests/           модульные тесты (node:test)
scripts/         вспомогательные скрипты (генерация иконок)
build/           ресурсы сборки (иконки)
```

Подробнее об архитектуре и контрактах IPC — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Команды

| Скрипт | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm run electron:dev` | Сборка main + запуск Electron в dev |
| `npm run typecheck` | Проверка типов рендерера |
| `npm test` | Модульные тесты (electron компилируется автоматически) |
| `npm run build` | Продакшн-сборка + установщики Windows |
| `npm run build:web` | Только фронтенд (для браузерного демо) |
