# Rust Server Manager LitvinBY

Десктопная утилита под Windows (и Linux) для управления выделенными серверами Rust: процессы, RCON, моды, вайпы и бэкапы — всё в одном окне.

> **Важно:** Неофициальный проект. Никак не связан с Facepunch Studios, названия Rust и Oxide принадлежат их владельцам.

## Что умеет

**Управление сервером**

- Запуск, остановка, рестарт `RustDedicatedServer.exe`. Если менеджер сам перезагрузился — подхватит уже активный процесс сервера.
- Встроенный watchdog: сам перезапускает сервер при крашах (до 3 раз за полчаса) или если консоль зависла.
- Конфиги: генерирует безопасный RCON-пароль, чистит кавычки в `server.cfg` для значений с пробелами.
- Игровые режимы (vanilla, softcore, hardcore, primitive), пути сохранений, карты (Procedural, CraggyIsland, кастомная ссылка), теги, тикрейт, порты, расписание вайпов.
- Обновление сервера и Oxide через SteamCMD в один клик, с прогрессом загрузки.

**RCON и игроки**

- WebRcon по стандарту Facepunch, с фолбэком.
- Живой лог консоли, поток чата, быстрые команды.
- Игроки онлайн, бан-листы, кик/бан, временные баны с авторазбаном.

**Плагины и Oxide**

- Установка, обновление и удаление Oxide (uMod) прямо в корневую папку сервера.
- Сканирование плагинов, отключение через `.disabled`, редактор JSON-конфигов.
- Поиск по каталогу uMod из приложения: описание, число скачиваний, установка `.cs` на лету.

**Вайпы, бэкапы и автоматизация**

- Ручной вайп: чистка `.map`/`.db`, новый сид, автостоп и автозапуск сервера.
- Планировщик: вайпы, ежедневные рестарты с предупреждениями в чат, автобэкапы с ротацией. Живёт в main-процессе — не прерывается, даже если закрыть окно.
- Бэкапы мира: создание, восстановление, удаление.

**Мониторинг и уведомления**

- Метрики в реальном времени: онлайн, FPS сервера, CPU, память.
- Графики истории посещаемости за день/неделю/месяц.
- Просмотрщик логов с поиском и фильтрами.
- Уведомления: системные пуши Windows + алерты в Discord и Telegram через вебхуки.

**Инфраструктура**

- Сворачивание в трей, автозапуск с Windows, автостарт серверов.
- Вкладка «Порты»: что занимает порты (показывает процесс-виновника), правила Windows Firewall (нужен админ/UAC), проверка портов по TCP снаружи.
- Linux: нативный `RustDedicated`, бета-ветки SteamCMD (`-beta`), процессы через `ps`, порты через `ss`/`netstat`, автозапуск через `.desktop`, сборка AppImage/deb в CI.
- Экспорт/импорт конфигов серверов, локализация RU/EN.

## Технологии

- UI: React 18, TypeScript, Tailwind CSS, lucide-react
- Бэкенд: Electron 29, Vite 5, i18next
- Ядро: Node.js, `ws` (WebRcon), `pidusage`, `adm-zip`
- Тесты: встроенный `node:test`, без внешних зависимостей
- Сборка: electron-builder (NSIS + portable)

## Быстрый старт

Нужен Node.js 20+ и Windows/Linux. Управление Windows Firewall работает только на Windows и под админом.

- `npm install` — зависимости
- `npm run dev` — Vite dev-server
- `npm run electron:dev` — компиляция main + окно Electron
- `npm run typecheck` — проверка типов рендерера
- `npm test` — компиляция main + модульные тесты
- `npm run build` — продакшн-сборка, установщики появятся в `/release`

## Структура проекта

- `electron/` — основной процесс: IPC, watchdog, RCON, планировщик, алерты
- `src/` — React-интерфейс (страницы, вкладки, контексты)
- `tests/` — тесты на `node:test`
- `scripts/` — вспомогательные скрипты (генерация иконок)
- `build/` — ресурсы сборщика (иконки, графика)

Детальнее про устройство и IPC-контракты — в [ARCHITECTURE.md](ARCHITECTURE.md).
